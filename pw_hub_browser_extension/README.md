# PW Hub Session Import

This Chromium extension transfers only PW Online cookies from Chrome or Edge to the account currently selected in PW Hub. Passwords and cookies from unrelated websites are never requested.

## Install in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `PwHubBrowserExtension` folder from the Game Tools installation.

## Install in Edge

1. Open `edge://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `PwHubBrowserExtension` folder from the Game Tools installation.

## Import a session

1. Select the target account in PW Hub.
2. Open the PW Hub tray menu and click **Connect browser extension**.
3. Open the extension, paste the six-digit pairing code, and click **Connect**.
4. Use Game Center to open the PW Online account page in Chrome or Edge.
5. After the page is authorized, open the extension and click **Import Current PW Session**.

PW Hub must be running during pairing and import. Pairing codes expire after five minutes.
